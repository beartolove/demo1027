# 待辦事項

一個可直接在瀏覽器開啟、免安裝且可離線使用的繁體中文待辦事項工具。目前正式版本為 **v1.0**。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可開始使用。任務資料只會儲存在目前瀏覽器的 LocalStorage，不會上傳至任何伺服器。

建議定期使用「匯出 CSV」備份資料；若清除瀏覽器網站資料，原先儲存的任務可能一併被清除。

## 主要功能

- 新增、編輯、刪除任務，並設定優先順序、分類、截止日期、描述及備註。
- 以核取方塊或編輯視窗切換任務狀態，完成時間會自動記錄。
- 顯示任務總數、未完成數、今日到期／已逾期數與完成率。
- 依任務狀態、優先順序、關鍵字篩選，並可依優先順序、截止日或建立日排序。
- 使用繁體中文欄名匯入或匯出 CSV，可方便地以 Excel 開啟。
- 「今日聚焦」可設定 3、4 或 5 件任務，支援點選加入、拖曳加入、移除與自動選入高優先任務。
- 左上角漢堡選單可調整字體大小、切換編輯／聚焦模式，以及切換明亮／深色模式；偏好設定會保留在目前瀏覽器。
- 響應式版面，可在桌面與手機瀏覽器使用。

## 顯示與工作模式

- **編輯模式**：以左右兩欄同時顯示「任務清單」與「今日聚焦」，清單區與聚焦區各自捲動，節省整頁捲動。
- **聚焦模式**：僅保留「今日聚焦」與左上角功能選單，減少干擾，適合專心完成當日最重要的事項。
- **字體大小**：可從選單以 A−／A＋在 90%、100%、110%、120% 間調整。
- **明亮／深色模式**：可依使用環境切換；深色模式中的聚焦區採淺藍與深藍層次、搭配黃白文字，確保可讀性。選擇會在下次開啟時維持。

## 燈箱操作

- 按下標題列的「新增待辦」會以燈箱開啟完整表單。
- 在待辦清單或今日聚焦中，點選任務列的非按鈕區域，即可開啟該任務的編輯燈箱。
- 燈箱中可正常儲存修改；若點擊燈箱外側或按下 Esc，會直接關閉且不儲存未提交的變更。

## CSV 與工時

- 匯入與匯出統一使用附件定義的固定 10 欄 CSV：任務編號、任務名稱、工作類別、優先順序、工作狀態、建立日期、預計完成日期、開工日期時間、完工日期時間、應注意事項。
- CSV 使用 `YYYY-MM-DD` 與 `YYYY-MM-DD HH:mm:ss`；網頁顯示則自動改為 `YYYY/MM/DD` 與 `YYYY/MM/DD HH:mm:ss`。
- 任務編號由系統自動產生、畫面不顯示；匯入時則須提供不重複的任務編號。
- 任務首次切換為進行中時記錄開工時間；切換為已完成時記錄完工時間，並在清單顯示「幾天幾小時」的實際工時。
- 應注意事項可在燈箱編輯；將游標停留在任務或今日聚焦項目上即可查看。

## 檔案結構

```text
index.html        正式使用的最新版本
README.md         本說明文件
CHANGELOG.md      版本變更紀錄
history/          保留每一個完整歷史版本
  todo_v0.1.html
  todo_v0.2.html
  todo_v0.3.html
  todo_v0.4.html
```

## 後續版本流程

1. 修改完成後，先將當前完整的 `index.html` 複製到 `history/`。
2. 歸檔檔名使用 `todo_v主版本.次版本.html`，例如 `todo_v0.5.html`。
3. 再更新 `index.html` 內的版本標籤與 HTML `<title>`。
4. 在 `CHANGELOG.md` 增加新版的日期與變更內容。

這個流程會讓 `index.html` 始終是可使用的最新正式版本，而每一版完整 HTML 都可從 `history/` 還原或比對。
